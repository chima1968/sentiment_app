# Sentiment Analyzer App

## Introduction
The Sentiment Analysis App is a robust and user-friendly application designed to classify text-based feedback into positive or negative sentiment categories. This tool leverages natural language processing to automate sentiment analysis, making it suitable for various use cases including customer feedback analysis, social media sentiment tracking, and product review evaluation.

## Features
1. Datasets such as Amazon's Alexa reviews and Yelp reviews are included.
2. Yelp reviews are split into training and testing sets.
3. Data exploration and cleaning have been performed.
4. Several models were created based on the prepared data.
5. The most efficient model was selected.
6. The models are stored as `.pkl` files, along with cross-validation and standardization/normalization files required for user input to fit into model parameters.
7. Functionality code is written in the `text_analyzer` file.
8. The main file uses Streamlit for a visually appealing interface.

## Installations
Install the following dependencies to run the app:
- Streamlit
- NLTK
- Pandas
- NumPy
- Jupyter Notebook
- Pickle
- Regular expressions
